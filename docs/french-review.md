# French review

Every French string added for the customer's account (`messages/account/fr.json`),
with the English beside it, for a native French speaker to check. The French was
written by Claude, not by a native speaker, so please read it as a customer in
Douala would.

**What to look for**

- Plain, natural French, not a stiff translation (same rule as the English: the
  customer should understand it at a glance).
- The words the rest of the site already uses: **formule** (plan), **ramassage**
  (pickup), **commande** (order), **vous** (formal "you").
- Gender and agreement: an order is feminine (_Reçue_, _Prête_, _Livrée_), a
  pickup is masculine (_Confirmé_, _Ramassé_), a plan is feminine (_Active_,
  _Annulée_). Check that each status agrees with the thing it describes.
- Amounts and dates are not here: they are written by the browser in the
  reader's language.
- Where the English has two forms (one / many), both are shown as `one / many`.

When a line is fine, leave it. When it is not, write the better French in the
last column and the catalogue can be updated from this file.
